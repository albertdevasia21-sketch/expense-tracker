# Hindsight — a decision journal

Log the decisions that matter, write down what you expect and how sure you are, then review them when the date comes round.

- **Due / Open / Reviewed** — every entry has a review date; overdue ones surface first.
- **Review** — record what happened, whether your expectation came true, whether the outcome was good, and whether the *process* was sound.
- **Insights** — calibration chart (stated confidence vs. reality), Brier score, a skill-vs-luck matrix, and breakdowns by state of mind and area of life.

`index.html` is self-contained: open it in any browser and data is kept in that browser's local storage (use Export for backups). `hindsight.html` is the same page in the format published as a claude.ai Artifact, where entries are stored privately for the owner.
